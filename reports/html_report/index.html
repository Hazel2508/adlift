FINAL PROJECT REPORT · SEPTEMBER 2026

AdLift

Advertising Incrementality
and Uplift Targeting

A reproducible benchmark analysis of randomized advertising effects, heterogeneous treatment-effect ranking, and budget-constrained targeting decisions.

AdLift asks whether randomized advertising creates incremental outcomes and whether a learned causal ranking can allocate a constrained budget better than conventional response targeting.

WHY THIS PROJECT

Incremental value comes from changing behavior, not merely observing it.

Some users would Visit or Convert without advertising. Others are unlikely to respond under either condition. A stronger targeting strategy prioritizes users for whom advertising is expected to create a positive difference.

THIS PROJECT

Measures average causal effects, models effect variation across anonymous feature patterns, ranks records by predicted incremental response, and compares uplift targeting with simpler alternatives.

The business problem is attribution versus incrementality. A conversion after an ad is not necessarily a conversion caused by the ad. The project separates users who would act anyway, users unlikely to act, and users whose behavior may change under treatment.

A/B TEST CALCULATION

Rates, effect sizes, uncertainty, and significance come from the randomized arms.

1
ARM RATES
p̂₁ = ΣYᵢTᵢ / n₁    p̂₀ = ΣYᵢ(1−Tᵢ) / n₀

n₁ = 11,882,655 Treatment records; n₀ = 2,096,937 Control records.

2
EFFECT SIZES
Absolute lift = p̂₁ − p̂₀
Relative lift = (p̂₁ − p̂₀) / p̂₀
3
INCREMENTAL OUTCOMES
n₁ × (p̂₁ − p̂₀)

An aggregate counterfactual estimate among treated records.

STATISTICAL INFERENCE
H₀: p₁ − p₀ = 0
SE = √[ p̂₁(1−p̂₁)/n₁ + p̂₀(1−p̂₀)/n₀ ]
95% confidence interval(p̂₁ − p̂₀) ± 1.96 × SE
Two-sided z testz = (p̂₁ − p̂₀) / SE
MultiplicityHolm adjustment across Visit and Conversion
Sensitivity checkTreatment-stratified binary-outcome bootstrap
Both outcomes reject H₀.Visit: z = 65.25, adjusted p < 1e−926
Conversion: z = 28.52, adjusted p = 7.308e−179

Why no CUPED? The release has no validated pre-period outcome or time field suitable for adjustment, so the primary estimate is the unadjusted randomized difference in means.

For each binary outcome, compute the observed Treatment and Control rates, subtract them for absolute lift, divide by the Control rate for relative lift, and multiply by the treated population for the incremental count. The analytical interval uses an unpooled standard error. A stratified bootstrap closely agrees with the analytical interval.
