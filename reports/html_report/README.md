# AdLift HTML report

Open `index.html` in a modern browser. The report is a static bundle and does not require a build step or network connection.

## Controls

- Left / Right arrows, Space, Page Up, or Page Down: navigate
- `O`: slide overview
- `F`: fullscreen
- `S`: presenter view with notes and timer
- `N`: speaker-note drawer
- Home / End: first or last page

The report uses the current Word report as its narrative source and the saved Phase 2 and Phase 4 figures as its numerical evidence. Targeting results remain exploratory and do not define an economically optimal coverage level.
